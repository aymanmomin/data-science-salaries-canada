# Data Science Salary Visualizations - Canada 2025

A collection of data visualizations analyzing salary trends across Canadian provinces for data science and tech roles, created to help students make informed career and co-op decisions.

---

## 📊 Visualization Projects

### 1. Data Science Salaries Across Canada (2025)

![Data Science Salaries](Viz_1_Data_Science_Salaries/data_science_salaries_canada_2025.png)

**Key Question:** Where should data science students apply for co-op positions to maximize salary potential?

**Key Findings:**
- 🥇 **BC leads** at $141k median salary (Vancouver tech hub)
- 🥈 **Ontario follows** at $129k (Toronto AI corridor - Vector Institute)
- 🥉 **Alberta competitive** at $114k (strong energy + tech data science market)
- 💰 **Entry to senior range:** $79k - $239k across Canada
- 📈 **Data science premium:** 10-20% higher pay vs software engineering

**What makes this useful:**
- Current 2025 data from Job Bank Canada, LinkedIn, and Glassdoor
- Compares median salaries AND complete salary ranges (junior to senior)
- Factors in cost of living considerations
- Identifies geographic trade-offs for career planning

## 🚀 Getting Started

### Prerequisites
```bash
# Python 3.13 or higher
python --version

# pip package manager
pip --version
```

### Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/data-science-salaries-canada.git
cd data-science-salaries-canada
```

2. Create and activate virtual environment (recommended):
```bash
# On Windows
python -m venv .venv
.venv\Scripts\activate

# On macOS/Linux
python3 -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:
```bash
pip install matplotlib numpy
```

### Running Visualizations

```bash
# Navigate to specific visualization
cd Viz_1_Data_Science_Salaries

# Run the script
python data_science_salaries_viz.py
```

The visualization will be generated as a PNG image in the same directory.
