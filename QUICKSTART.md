# Data Science Salary Analysis - Canada 2025

## 🚀 Quick Start Guide

### 1. Install Dependencies

```bash
# Make sure you're in the project directory
pip install -r requirements.txt
```

### 2. Run the Interactive Dashboard

The easiest way to explore the data:

```bash
streamlit run app.py
```

Then open **http://localhost:8501** in your browser.

---

## ✨ Available Features

1. **Filter by Province** - Compare specific provinces
2. **Toggle Salary Types** - View nominal vs cost-of-living adjusted
3. **Interactive Charts** - Explore median salaries and growth potential
4. **Detailed Tables** - Sort and analyze complete data
5. **Student Insights** - Get personalized recommendations

### Project Highlights

- **Cost-of-Living Adjustment**: See real purchasing power, not just raw numbers
- **Career Growth Analysis**: Understand entry-level to senior progression
- **Multiple Visualizations**: Static charts + interactive dashboard + Jupyter notebooks
- **Student-Focused**: Tailored for co-op and career planning

### Data Sources

- Government of Canada Job Bank
- LinkedIn Salary Insights
- Glassdoor Canada
- Numbeo Cost of Living Index (2025)
